# Puente de Diario Federal Studio

Recibe el programa desde la consola del estudio y lo emite en YouTube.

Secretos (Settings → Variables and secrets → New secret):
- `YOUTUBE_CLAVE`: la clave de transmisión de YouTube Studio.
- `CLAVE_ESTUDIO`: una contraseña a elección; se escribe en la consola para poder emitir.
